Bloque 1 — El Tidyverse (≈ 10 minutos)

¿Qué es el Tidyverse?

El Tidyverse es una colección de paquetes de R con una filosofía coherente para el análisis de datos. Todos comparten la misma estructura de entrada/salida (el tibble), el mismo estilo de código (verbos + pipe) y documentación consistente.

Paquete Función Semana
readr Importar CSV y archivos de texto Hoy
readxl Importar archivos Excel Hoy
dplyr Manipular y transformar datos Hoy
tidyr Ordenar y pivotar datos Semana 5
ggplot2 Visualización de datos Semana 6

El operador pipe |>

# Sin pipe — se lee de adentro hacia afuera:
resultado_sin_pipe <- round(sqrt(log(100)), digits = 2)

# Con pipe — se lee de izquierda a derecha:
resultado_con_pipe <- 100 |> log() |> sqrt() |> round(digits = 2)

resultado_sin_pipe
[1] 2.15
resultado_con_pipe   # mismo resultado, código más legible
[1] 2.15
Atajo de teclado del pipe

Ctrl + Shift + M en RStudio genera |> automáticamente.

Verifica en: Tools → Global Options → Code → Use native pipe operator

Bloque 3 — dplyr: los 5 verbos (≈ 40 minutos)

# Regla mnemotécnica:
#   filter()    → filas que CUMPLEN una condición
#   select()    → columnas que QUIERO
#   mutate()    → columnas nuevas o TRANSFORMADAS
#   arrange()   → filas en cierto ORDEN
#   summarise() → una TABLA RESUMEN por grupo

3.1 filter() — seleccionar filas

# Registros de Barranquilla:
fauna_barranquilla <- fauna |>
  filter(municipio == "Barranquilla")

nrow(fauna)
[1] 198
nrow(fauna_barranquilla)
[1] 24
# Especies amenazadas (VU, EN o CR):
fauna_amenazadas <- fauna |>
  filter(estado_conservacion %in% c("VU", "EN", "CR"))

nrow(fauna_amenazadas)
[1] 16
# Condición múltiple: bosque seco CON más de 5 individuos
# La coma dentro de filter() equivale a & (Y lógico)
fauna_bosque_abundante <- fauna |>
  filter(ecosistema == "bosque_seco", n_individuos > 5)

nrow(fauna_bosque_abundante)
[1] 4

3.3 mutate() — crear o transformar columnas

# log1p(x) = log(x + 1) — evita log(0) = -Inf cuando hay ceros
fauna <- fauna |>
  mutate(log_individuos = log1p(n_individuos))
# case_when() — equivalente de if-else múltiple dentro de mutate()
fauna <- fauna |>
  mutate(
    categoria_abundancia = case_when(
      n_individuos <= 5  ~ "Baja",
      n_individuos <= 20 ~ "Media",
      n_individuos >  20 ~ "Alta"
    )
  )
# Extraer el año de una fecha:
fauna <- fauna |>
  mutate(anio = format(fecha_obs, "%Y"))

3.5 summarise() + group_by() — resumir por grupo

# Siempre van juntos: group_by() → summarise()
resumen_ecosistema <- fauna |>
  group_by(ecosistema) |>
  summarise(
    n_registros    = n(),
    n_especies     = n_distinct(especie),
    total_indiv    = sum(n_individuos, na.rm = TRUE),
    media_indiv    = mean(n_individuos, na.rm = TRUE)
  ) |>
  arrange(desc(total_indiv))

Bloque 4 — Ejercicio ABP en parejas (≈ 20 minutos)

Contexto: El programa de monitoreo necesita identificar las 3 especies más registradas por ecosistema, y saber qué proporción de esos registros prioritarios corresponde a especies amenazadas.

Trabajen en parejas (15 min), luego presentan su solución.

Una solución posible (revelar al final) 
# Top 3 especies por ecosistema según número de registros:
fauna |>
  group_by(ecosistema, especie) |>
  summarise(
    n_registros = n(),
    total_indiv = sum(n_individuos, na.rm = TRUE),
    .groups     = "drop"
  ) |>
  group_by(ecosistema) |>
  slice_max(order_by = n_registros, n = 3) |>
  arrange(ecosistema, desc(n_registros))
# A tibble: 19 × 4

## Bloque 1 — El Tidyverse *(≈ 10 minutos)*

### ¿Qué es el Tidyverse?

El Tidyverse es una colección de paquetes de R con una filosofía coherente para el análisis de datos. Todos comparten la misma estructura de entrada/salida (el **tibble**), el mismo estilo de código (verbos + pipe) y documentación consistente.

| Paquete | Función | Semana |
|---------|---------|--------|
| `readr` | Importar CSV y archivos de texto | **Hoy** |
| `readxl` | Importar archivos Excel | **Hoy** |
| `dplyr` | Manipular y transformar datos | **Hoy** |
| `tidyr` | Ordenar y pivotar datos | Semana 5 |
| `ggplot2` | Visualización de datos | Semana 6 |

### Tibble vs data.frame

```{r}
#| label: tibble-vs-df
df_clasico <- data.frame(
  especie = c("Ardea alba", "Egretta thula", "Fregata magnificens"),
  conteo  = c(45L, 120L, 8L),
  fecha   = as.Date(c("2024-01-15", "2024-01-15", "2024-01-16"))
)

tbl_moderno <- tibble(
  especie = c("Ardea alba", "Egretta thula", "Fregata magnificens"),
  conteo  = c(45L, 120L, 8L),
  fecha   = as.Date(c("2024-01-15", "2024-01-15", "2024-01-16"))
)

df_clasico    # imprime TODO, sin información de tipos
tbl_moderno   # máximo 10 filas, muestra tipos (<chr>, <int>, <date>)
```

### El operador pipe `|>`

```{r}
#| label: pipe-demo
# Sin pipe — se lee de adentro hacia afuera:
resultado_sin_pipe <- round(sqrt(log(100)), digits = 2)

# Con pipe — se lee de izquierda a derecha:
resultado_con_pipe <- 100 |> log() |> sqrt() |> round(digits = 2)

resultado_sin_pipe
resultado_con_pipe   # mismo resultado, código más legible
```

::: {.callout-tip}
## Atajo de teclado del pipe

**Ctrl + Shift + M** en RStudio genera `|>` automáticamente.

Verifica en: `Tools → Global Options → Code → Use native pipe operator`
:::

## Bloque 2 — Importación de datos *(≈ 20 minutos)*

### `read_csv()` vs `read.csv()`

| Característica | `read.csv()` (base R) | `read_csv()` (readr) |
|---|---|---|
| Resultado | `data.frame` | `tibble` |
| Mensajes de parsing | Ninguno | Informa tipo de cada columna |
| NA personalizados | Manual | Argumento `na` |
| Velocidad | Lenta | Rápida |

**Regla práctica:** en el Tidyverse, siempre preferimos `read_csv()`.

## Bloque 3 — dplyr: los 5 verbos *(≈ 40 minutos)*

```{r}
#| label: verbos-resumen
# Regla mnemotécnica:
#   filter()    → filas que CUMPLEN una condición
#   select()    → columnas que QUIERO
#   mutate()    → columnas nuevas o TRANSFORMADAS
#   arrange()   → filas en cierto ORDEN
#   summarise() → una TABLA RESUMEN por grupo
```

### 3.1 `filter()` — seleccionar filas

```{r}
#| label: filter-basico
# Registros de Barranquilla:
fauna_barranquilla <- fauna |>
  filter(municipio == "Barranquilla")

nrow(fauna)
nrow(fauna_barranquilla)
```

```{r}
#| label: filter-in
# Especies amenazadas (VU, EN o CR):
fauna_amenazadas <- fauna |>
  filter(estado_conservacion %in% c("VU", "EN", "CR"))

nrow(fauna_amenazadas)
```

```{r}
#| label: filter-multiple
# Condición múltiple: bosque seco CON más de 5 individuos
# La coma dentro de filter() equivale a & (Y lógico)
fauna_bosque_abundante <- fauna |>
  filter(ecosistema == "bosque_seco", n_individuos > 5)

nrow(fauna_bosque_abundante)
```

> **Pregunta:** ¿Cuántas especies amenazadas hay en manglares? ¿Cómo escribirían ese filtro?

### 3.2 `select()` — seleccionar columnas

```{r}
#| label: select-nombres
# Por nombre explícito:
fauna |>
  select(especie, nombre_comun, clase, ecosistema, n_individuos)
```

```{r}
#| label: select-helpers
# Helpers de selección:
fauna |> select(starts_with("fecha"))    # columnas que empiezan con "fecha"
fauna |> select(where(is.numeric))       # solo columnas numéricas
fauna |> select(where(is.character))     # solo columnas de texto
```

```{r}
#| label: select-excluir
# Excluir columnas con -:
fauna |> select(-latitud, -longitud)
```

### 3.3 `mutate()` — crear o transformar columnas

```{r}
#| label: mutate-log
# log1p(x) = log(x + 1) — evita log(0) = -Inf cuando hay ceros
fauna <- fauna |>
  mutate(log_individuos = log1p(n_individuos))
```

```{r}
#| label: mutate-casewhen
# case_when() — equivalente de if-else múltiple dentro de mutate()
fauna <- fauna |>
  mutate(
    categoria_abundancia = case_when(
      n_individuos <= 5  ~ "Baja",
      n_individuos <= 20 ~ "Media",
      n_individuos >  20 ~ "Alta"
    )
  )
```

```{r}
#| label: mutate-anio
# Extraer el año de una fecha:
fauna <- fauna |>
  mutate(anio = format(fecha_obs, "%Y"))

fauna |>
  select(especie, n_individuos, log_individuos, categoria_abundancia, anio)
```

> **Pregunta:** ¿Por qué usamos `log1p()` en lugar de `log()`? ¿Qué ecosistemas tienen más registros en categoría "Alta"?

### 3.4 `arrange()` — ordenar filas

```{r}
#| label: arrange-desc
# De mayor a menor número de individuos:
fauna |>
  arrange(desc(n_individuos)) |>
  select(especie, municipio, ecosistema, n_individuos)
```

```{r}
#| label: arrange-multiple
# Dos criterios: ecosistema (asc) + n_individuos (desc):
fauna |>
  arrange(ecosistema, desc(n_individuos)) |>
  select(especie, ecosistema, n_individuos) |>
  head(10)
```

### 3.5 `summarise()` + `group_by()` — resumir por grupo

```{r}
#| label: summarise-ecosistema
# Siempre van juntos: group_by() → summarise()
resumen_ecosistema <- fauna |>
  group_by(ecosistema) |>
  summarise(
    n_registros    = n(),
    n_especies     = n_distinct(especie),
    total_indiv    = sum(n_individuos, na.rm = TRUE),
    media_indiv    = mean(n_individuos, na.rm = TRUE)
  ) |>
  arrange(desc(total_indiv))

resumen_ecosistema
```

```{r}
#| label: summarise-dos-grupos
# Dos variables de agrupación:
fauna |>
  group_by(clase, estado_conservacion) |>
  summarise(n_registros = n(), .groups = "drop")
```

> **Pregunta:** ¿Cuál es el ecosistema con mayor riqueza de especies? ¿Es el mismo con mayor número de individuos? ¿Qué explicación biológica plantearías?

### 3.6 Pipelines: combinando verbos

```{r}
#| label: pipeline-top-clase
# ¿Cuántos registros y qué riqueza de especies por clase taxonómica?
fauna |>
  group_by(clase) |>
  summarise(
    n_registros = n(),
    n_especies  = n_distinct(especie),
    total_indiv = sum(n_individuos, na.rm = TRUE)
  ) |>
  arrange(desc(n_registros))
```

```{r}
#| label: pipeline-amenaza
# Proporción de registros por categoría de amenaza:
fauna |>
  group_by(estado_conservacion) |>
  summarise(n = n()) |>
  mutate(porcentaje = round(n / sum(n) * 100, 1)) |>
  arrange(desc(porcentaje))
```

## Bloque 4 — Ejercicio ABP en parejas *(≈ 20 minutos)*

**Contexto:** El programa de monitoreo necesita identificar las 3 especies más registradas por ecosistema, y saber qué proporción de esos registros prioritarios corresponde a especies amenazadas.

Trabajen en parejas (15 min), luego presentan su solución.

::: {.callout-tip collapse="true"}
## Una solución posible (revelar al final)

```{r}
#| label: solucion-abp
# Top 3 especies por ecosistema según número de registros:
fauna |>
  group_by(ecosistema, especie) |>
  summarise(
    n_registros = n(),
    total_indiv = sum(n_individuos, na.rm = TRUE),
    .groups     = "drop"
  ) |>
  group_by(ecosistema) |>
  slice_max(order_by = n_registros, n = 3) |>
  arrange(ecosistema, desc(n_registros))
```
