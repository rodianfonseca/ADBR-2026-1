Al finalizar esta sesión, el estudiante será capaz de:

  1. Construir matrices y data frames combinando vectores de distintos tipos

  5. Escribir bucles for y while para automatizar operaciones sobre estructuras de datos

2. Matrices

Una matriz es un arreglo rectangular de elementos del mismo tipo, organizado en filas y columnas.

# Conteos de aves por zona y temporada en la Ciénaga de Mallorquín
# Zonas: sur, centro, norte — Temporadas: seca, lluviosa
conteos_matriz <- matrix(
  data  = c(47, 89, 156,    # temporada seca: sur, centro, norte
            62, 134, 201),  # temporada lluviosa: sur, centro, norte
  nrow  = 2,
  ncol  = 3,
  byrow = TRUE              # llenamos fila por fila (por temporada)

Limitación de las matrices: solo un tipo de dato

Si mezclamos tipos, R fuerza coerción:

matriz_mixta <- matrix(c(1, 2, "tres", 4), nrow = 2)
class(matriz_mixta[1, 1])  # "character" — el número fue convertido a texto
[1] "character"

Esto es problemático en datos biológicos reales que mezclan nombres de especie (character) con conteos (integer) y coordenadas (numeric). La solución: data frames.

3. Data frames — la estructura central del análisis biológico

Un data frame es una tabla con filas (observaciones) y columnas (variables). Cada columna es un vector, pero columnas distintas pueden ser de tipos distintos.

3.1 Creación

# Dataset: aves acuáticas — Ciénaga de Mallorquín, Atlántico
aves_df <- data.frame(
  especie      = c("Pelecanus occidentalis", "Egretta thula",
                   "Ardea alba", "Fregata magnificens", "Nycticorax nycticorax"),
  n_individuos = c(47L, 312L, 89L, 23L, 156L),

  confirmado   = c(TRUE, TRUE, FALSE, TRUE, FALSE),

4. Listas — estructuras flexibles y jerárquicas

Una lista puede contener objetos de cualquier tipo y tamaño. Es la estructura más flexible de R.

4.1 Creación

Error frecuente: if() con un vector

if() solo acepta una sola condición (TRUE o FALSE). Si le pasamos un vector, R produce el error “the condition has length > 1”. Para vectores, usamos ifelse().

5.3 switch() — alternativa a múltiples if/else

clasificar_ecosistema <- function(tipo) {
  switch(tipo,
    "manglar"     = "Ecosistema costero salino — alta prioridad de conservación",
    "bosque_seco" = "Ecosistema continental — amenazado en el Caribe colombiano",
    "humedal"     = "Ecosistema acuático continental — Convenio Ramsar",
    "Tipo de ecosistema no reconocido"   # caso por defecto
  )
}

7. Caso integrador — Sistema de alerta de poblaciones

Combinamos data frames, condicionales y bucles en un flujo de análisis completo.

cat("=== SISTEMA DE ALERTA DE POBLACIONES ===\n\n")
=== SISTEMA DE ALERTA DE POBLACIONES ===
for (i in 1:nrow(aves_df)) {
  sp         <- aves_df$especie[i]
  n          <- aves_df$n_individuos[i]
  confirmado <- aves_df$confirmado[i]

  if (!confirmado) {
    cat(sp, "— SIN CONFIRMAR (requiere verificación)\n")
    next
  }

  if (n >= 200) {
    estado <- "VERDE   — Población estable"
  } else if (n >= 50) {
    estado <- "AMARILLO — Monitoreo frecuente"
  } else {
    estado <- "ROJO    — Alerta de conservación"
  }

  cat(sprintf("%-30s | N = %3d | %s\n", sp, n, estado))
}

8. Ejercicio en clase

Tiempo: 10 minutos · Trabajen en parejas

Contexto: El equipo de conservación de la Ciénaga de Mallorquín necesita un reporte automatizado de las aves de zona norte.

a) Crea un data frame aves_norte con solo las aves de zona norte. ¿Cuántas especies hay? ¿Cuántos individuos en total?

b) Con un bucle for, imprime por especie: "La [especie] tiene un pico de [X] cm, clasificado como [largo/corto]" (Criterio: largo si long_culmen > 15, corto si no)

c) Crea una lista reporte_norte con tres componentes: datos, n_spp, total_n. Verifica con str().

Pistas 
# a) Filtrar zona norte
aves_norte <- aves_df[aves_df$zona == "norte", ]

# b) Bucle con condicional
for (i in 1:nrow(aves_norte)) {
  clase_pico <- ifelse(aves_norte$long_culmen[i] > 15, "largo", "corto")
  cat(sprintf("La %s tiene un pico de %.1f cm, clasificado como %s\n",
              aves_norte$especie[i], aves_norte$long_culmen[i], clase_pico))
}

# c) Lista de resultados
reporte_norte <- list(
  datos   = aves_norte,
  n_spp   = nrow(aves_norte),
  total_n = sum(aves_norte$n_individuos)
)

## 2. Matrices

Una matriz es un arreglo rectangular de elementos del **mismo tipo**, organizado en filas y columnas.

```{r}
#| label: matrices
# Conteos de aves por zona y temporada en la Ciénaga de Mallorquín
# Zonas: sur, centro, norte — Temporadas: seca, lluviosa
conteos_matriz <- matrix(
  data  = c(47, 89, 156,    # temporada seca: sur, centro, norte
            62, 134, 201),  # temporada lluviosa: sur, centro, norte
  nrow  = 2,
  ncol  = 3,
  byrow = TRUE              # llenamos fila por fila (por temporada)
)

rownames(conteos_matriz) <- c("seca", "lluviosa")
colnames(conteos_matriz) <- c("zona_sur", "zona_centro", "zona_norte")

conteos_matriz
```

```{r}
#| label: indexacion-matrices
# Indexación en matrices: [fila, columna]
conteos_matriz[1, ]                           # temporada seca completa
conteos_matriz[, 3]                           # zona norte completa
conteos_matriz["lluviosa", "zona_centro"]     # celda específica por nombre

# Operaciones sobre matrices — también son vectorizadas
rowSums(conteos_matriz)    # total de aves por temporada
colSums(conteos_matriz)    # total de aves por zona
```

::: {.callout-warning}
## Limitación de las matrices: solo un tipo de dato

Si mezclamos tipos, R fuerza coerción:

```{r}
#| label: coercion-matriz
matriz_mixta <- matrix(c(1, 2, "tres", 4), nrow = 2)
class(matriz_mixta[1, 1])  # "character" — el número fue convertido a texto
```

Esto es problemático en datos biológicos reales que mezclan nombres de especie (character) con conteos (integer) y coordenadas (numeric). **La solución: data frames.**
:::

## 3. Data frames — la estructura central del análisis biológico

Un data frame es una tabla con filas (observaciones) y columnas (variables). Cada columna es un vector, pero columnas distintas pueden ser de tipos distintos.

### 3.1 Creación

```{r}
#| label: data-frame-creacion
# Dataset: aves acuáticas — Ciénaga de Mallorquín, Atlántico
aves_df <- data.frame(
  especie      = c("Pelecanus occidentalis", "Egretta thula",
                   "Ardea alba", "Fregata magnificens", "Nycticorax nycticorax"),
  n_individuos = c(47L, 312L, 89L, 23L, 156L),
  zona         = factor(c("norte", "centro", "norte", "norte", "sur"),
                        levels = c("sur", "centro", "norte")),
  confirmado   = c(TRUE, TRUE, FALSE, TRUE, FALSE),
  long_culmen  = c(28.4, 7.2, 12.1, 19.8, 6.3),   # longitud del pico en cm
  peso_g       = c(3100, 410, 850, 1450, 800),      # peso promedio en gramos
  stringsAsFactors = FALSE
)
```

## 4. Listas — estructuras flexibles y jerárquicas

Una lista puede contener objetos de **cualquier tipo y tamaño**. Es la estructura más flexible de R.

### 4.1 Creación

```{r}
#| label: lista-creacion
# Expediente completo de un sitio de monitoreo de manglar
sitio_mallorquin <- list(
  nombre           = "Ciénaga de Mallorquín",
  departamento     = "Atlántico",
  coordenadas      = c(lat = 11.044, lon = -74.869),  # WGS84
  area_ha          = 1027,
  tipo_ecosistema  = factor("manglar", levels = c("manglar", "bosque_seco", "humedal")),
  especies_manglar = c("Rhizophora mangle", "Avicennia germinans", "Laguncularia racemosa"),
  conteos_aves     = aves_df,     # ¡data frame dentro de una lista!
  fecha_ultimo_monitoreo = as.Date("2025-11-20"),
  tiene_veda       = TRUE
)

length(sitio_mallorquin)   # 9 componentes
names(sitio_mallorquin)    # nombres de cada componente
```

### 4.2 Indexación

```{r}
#| label: lista-indexacion
# Tres formas equivalentes de acceder a un componente:
sitio_mallorquin[[1]]            # por posición
```

## 5. Condicionales

### 5.1 `if / else`

```{r}
#| label: if-else
n_individuos_garceta <- 312   # Egretta thula en el último conteo

if (n_individuos_garceta > 200) {
  cat("Población abundante: se recomienda estimación por transectos.\n")
} else if (n_individuos_garceta > 50) {
  cat("Población media: conteo directo es viable.\n")
} else {
  cat("Población baja: se activa protocolo de vigilancia.\n")
}
```

### 5.2 `ifelse()` — versión vectorizada

```{r}
#| label: ifelse-vectorizado
# Clasifica cada especie según su abundancia
estado_poblacion <- ifelse(aves_df$n_individuos > 100, "abundante", "escaso")
names(estado_poblacion) <- aves_df$especie
estado_poblacion
```

::: {.callout-warning}
## Error frecuente: `if()` con un vector

`if()` solo acepta **una sola** condición (`TRUE` o `FALSE`). Si le pasamos un vector, R produce el error *"the condition has length > 1"*. Para vectores, usamos `ifelse()`.
:::

### 5.3 `switch()` — alternativa a múltiples if/else

```{r}
#| label: switch
clasificar_ecosistema <- function(tipo) {
  switch(tipo,
    "manglar"     = "Ecosistema costero salino — alta prioridad de conservación",
    "bosque_seco" = "Ecosistema continental — amenazado en el Caribe colombiano",
    "humedal"     = "Ecosistema acuático continental — Convenio Ramsar",
    "Tipo de ecosistema no reconocido"   # caso por defecto
  )
}

clasificar_ecosistema("manglar")
clasificar_ecosistema("coral")   # activará el caso por defecto
```

## 6. Bucles

### 6.1 `for` — iterar sobre un conjunto conocido

```{r}
#| label: bucle-for
# Índice morfométrico por especie (peso/culmen²)
cat("=== ÍNDICE MORFOMÉTRICO POR ESPECIE ===\n")
for (i in 1:nrow(aves_df)) {
  imc <- aves_df$peso_g[i] / (aves_df$long_culmen[i]^2)
  cat(sprintf("%-30s: %.2f\n", aves_df$especie[i], imc))
}
```

```{r}
#| label: bucle-for-acumulador
# Pre-alocar el vector antes del bucle — mejor práctica de rendimiento
n_letras <- vector("integer", length = nrow(aves_df))
for (i in seq_along(aves_df$especie)) {
  n_letras[i] <- nchar(aves_df$especie[i])
}
names(n_letras) <- aves_df$especie
n_letras
```

### 6.2 `while` — iterar mientras una condición sea verdadera

```{r}
#| label: bucle-while
# ¿Cuántos muestreos para acumular 500 aves?
set.seed(20953)
total_aves  <- 0L
n_muestreos <- 0L

while (total_aves < 500L) {
  conteo_sesion <- sample(30:80, size = 1)
  total_aves    <- total_aves + conteo_sesion
  n_muestreos   <- n_muestreos + 1L
}
cat(sprintf("Se necesitaron %d muestreos para acumular %d individuos.\n",
            n_muestreos, total_aves))
```

### 6.3 `next` y `break` — control dentro del bucle

```{r}
#| label: next-break
# next: saltar registros sin confirmar
cat("=== REGISTROS CONFIRMADOS ===\n")
for (i in 1:nrow(aves_df)) {
  if (!aves_df$confirmado[i]) next
  cat(sprintf("%s — %d individuos en zona %s\n",
              aves_df$especie[i], aves_df$n_individuos[i], aves_df$zona[i]))
}
```

```{r}
#| label: break-ejemplo
# break: salir al encontrar el primer resultado
cat("\n=== PRIMERA ESPECIE SUPERABUNDANTE ===\n")
for (i in 1:nrow(aves_df)) {
  if (aves_df$n_individuos[i] > 200) {
    cat("Primera especie con > 200 individuos:", aves_df$especie[i], "\n")
    break
  }
}
```

## 7. Caso integrador — Sistema de alerta de poblaciones

Combinamos data frames, condicionales y bucles en un flujo de análisis completo.

```{r}
#| label: caso-integrador
cat("=== SISTEMA DE ALERTA DE POBLACIONES ===\n\n")

for (i in 1:nrow(aves_df)) {
  sp         <- aves_df$especie[i]
  n          <- aves_df$n_individuos[i]
  confirmado <- aves_df$confirmado[i]

  if (!confirmado) {
    cat(sp, "— SIN CONFIRMAR (requiere verificación)\n")
    next
  }

  if (n >= 200) {
    estado <- "VERDE   — Población estable"
  } else if (n >= 50) {
    estado <- "AMARILLO — Monitoreo frecuente"
  } else {
    estado <- "ROJO    — Alerta de conservación"
  }

  cat(sprintf("%-30s | N = %3d | %s\n", sp, n, estado))
}
```

```r
aves_norte <- aves_df[aves_df$zona == "norte", ]
```
